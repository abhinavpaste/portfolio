HOW TO RUN How to create and run your React program from scratch You need to create a React project, put the code into App.js and index.js, and run it in your browser. Step 1: Install Node.js If you haven't installed Node.js: 1. Go to nodejs.org. 2. Download the LTS version. 3. Install it using the default options. 4. Open Command Prompt (CMD) and check the installation: node -v npm -v If both commands display version numbers, continue. Step 2: Create a React project Open CMD and run these commands one at a time: npm create vite@latest student-counter -- --template react If it asks for permission to install a package, type y and press Enter. Then run: cd student-counter npm install This creates a folder named student-counter containing your React project. Step 3: Open the project in VS Code Run this command in the same CMD window: code . If it doesn't work, open VS Code manually and select File → Open Folder → student-counter. In the left Explorer panel, open the src folder. You will see files similar to these: student-counter node_modules src App.jsx — main program main.jsx — starts React index.css package.json Important: Vite uses App.jsx and main.jsx by default. These serve the same purposes as the App.js and index.js shown in your screenshot.
